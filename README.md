Program Description
This C++ program calculates the sum of the first 50 natural numbers using a for loop. It also verifies the result using the mathematical formula:

Formula: n(n + 1) / 2

Where n = 50.

Calculation
50 × (50 + 1) / 2 = 1275

Sample Output
Sum of first 50 natural numbers (loop): 1275
Sum of first 50 natural numbers (formula): 1275
Verification successful!
